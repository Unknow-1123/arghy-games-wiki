
# A.R.GH.Y Games Wiki — Guides

This directory contains individual walkthroughs, task guides,
puzzle solutions and gameplay tutorials.

## Games

NGPAM guides will be organized here.

Planned guide types:
- Individual task walkthroughs
- Step-by-step objectives
- Puzzle solutions
- Item locations
- Secrets and collectibles

### A Night With August
ANWA guides will be organized here.

Planned guide types:
- Beginner's guide
- Location walkthroughs
- Puzzle solutions
- Gameplay mechanics
- Survival strategies

## Writing Guidelines

1. Guides must be based on verified gameplay.
2. Explain every step clearly.
3. Mention the relevant game version when known.
4. Add screenshots when they help explain a step.
5. Clearly mark spoilers when necessary.
6. Never publish guessed solutions as confirmed facts.

## File Naming

Use lowercase names and hyphens.

Examples:
- `ngpam-first-task.html`
- `ngpam-puzzle-solutions.html`
- `anwa-beginners-guide.html`
