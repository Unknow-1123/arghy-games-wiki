
# A.R.GH.Y Games Wiki — Images

This directory stores images used by the official game Wiki.

## Image Guidelines

- Prefer original in-game screenshots.
- Use clear and readable images.
- Avoid unrelated stock images.
- Do not upload copyrighted images without permission.
- Use descriptive lowercase filenames.
- Keep image file sizes optimized for web performance.

## Naming Examples

- `ngpam-main-menu.png`
- `ngpam-gameplay-01.jpg`
- `anwa-main-menu.png`
- `anwa-location-01.jpg`

## Adding Images

Upload images into this directory through GitHub.

Example:

`images/ngpam-gameplay-01.jpg`

Reference an image from a root-level HTML page using:

`images/ngpam-gameplay-01.jpg`
